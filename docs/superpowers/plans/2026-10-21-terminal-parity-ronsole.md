## Global Constraints

* Крейт платформенно-нейтрален: никакого `std::os::*`, `libc`, `/proc`, env, потоков, каналов, I/O; допустимы `std::time::Instant` (тип) и `Arc`; `Instant::now()` крейт не вызывает — время приходит аргументом `now` (спека 4.1).
* Зависимости крейта — только `vte = { version = "0.15.0", default-features = false, features = ["std"] }` и `unicode-width = "0.2.2"`; крейт реэкспортирует `vte` (`pub use vte;`). Base64 и percent-decoding пишутся в крейте руками.
* `size_of::<Cell>() <= 24` — тест крейта (спека 4.5).
* 2026: срок `now + 150 мс` от первого `h`, повторный `h` не продлевает; буфер до 2 MiB; ёмкость между обновлениями — до 64 KiB, больше освобождается; без 2026 буфер не выделяется (спека 5.4).
* Ответы одного вызова `advance`/`flush_expired` — один `reply`, буфер ≤ 64 KiB, сверх — отбрасываются; хост шлёт копию `try_send` в `sync_channel(32)` (спека 4.3, решение 17).
* OSC 52: декодированный размер ≤ 4 MiB; длина `Pd` больше `4·⌈4 MiB / 3⌉` = 5 592 408 байт — игнор без декодирования (спека 5.7). OSC 7: путь ≤ 4096 байт после декодирования (5.8). OSC 8: URI ≤ 2083 байт (5.5).
* Kitty: поддержаны флаги 1, 2, 8, 16; флаг 4 маскируется; стеки основного и альтернативного экрана по 32; набор отправленных клавиш — массив на 16 пар без аллокаций (5.3).
* Без событий крейт не аллоцирует; буферы переиспользуются через `clear()` (4.3).
* Ronsole hot paths (`AGENTS.md:108`): в путях рендера, кадра, ввода, вывода PTY — без файлового I/O, `/proc`, буфера обмена, subprocess. Мьютекс сетки не держать во время буфера обмена, процесса и прочей блокирующей работы (`AGENTS.md:114`).
* Рендер: Y текста и линий — целые, от округлённого baseline; толщина линии `max(1, round(scale))` px; без накопления дробных шагов (спека 6.2).
* Форматтер не запускать (дерево не rustfmt-clean, `AGENTS.md:235`): стиль соседних строк — руками. Коммиты — явными путями, без `git add -A/.` (`AGENTS.md:272`).
* Тесты: узкий прогон `make test TEST_FILTER=<подстрока имени>`, один тест `make test-one TEST='<путь::имя>'`, в foreground; полный `make codex_test` — только главная на воротах этапа.
